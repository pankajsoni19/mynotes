Using MyNotes

Home and URLs

After sign-in, Home links to Notes, Files, and the Bin. Every view has its own address.

URLView
/Home
/notesNotes, all folders; resumes your last note
/notes/folder/<folder-id>Notes in one folder
/notes/sharedNotes shared with you
/notes/<note-id>One note in the editor
/files, /files/folder/<folder-id>, /files/sharedFiles, by folder or shared with you
/files/<file-id>One file's preview and details
/binBin

Unknown paths open Home. A link to something missing, binned, or not shared with you falls back to the list with a message. A signed-out visit shows the login screen, then continues to the link. On phones, Back steps from the editor or preview to the list, the folders, and Home without leaving the site; with a dialog or sheet open, Back only closes it.

Using MyNotes

Notes editor

Type / for headings, lists, checklists, quotes, code blocks, images, and tables.

Images

/image, paste, or drop uploads a PNG, JPEG, GIF, or WebP into the note's folder in Files and embeds it. Removing it from the note keeps the file.

Tables

/table inserts a 3×3 table with a header row. A floating toolbar edits rows and columns; tables save as Markdown pipe tables.

Download as PDF

From the editor toolbar or the phone actions menu. The browser's print dialog opens with a print layout; choose Save as PDF.

Images follow the folder's sharing. A note shared more widely than its folder shows those readers a broken image. Nothing leaks; share the folder or the image too.
Using MyNotes

Files

Documents live in the same folders as notes. Any type is stored; only safe types are shown in the app.

Detected typePreview
PNG, JPEG, GIF, WebPShown inline
PDFOpens in a new tab
UTF-8 text (.txt, .md, .csv, .tsv, .log, .json)First 1 MiB as plain text
MP3, Ogg, WAV, M4A, MP4, WebMAudio or video player
Everything else, including SVG, HTML, Office files, archivesDownload only

The server detects the type from the file's first bytes, never from its name or the browser. Upload with the button, by dropping files on the list, or from the phone upload sheet; uploads run two at a time with progress, cancel, and retry. Each row's ⋯ menu (an action sheet on phones) offers Download, Rename, Move, Share, and Delete. Drag a file onto a folder to move it. Delete moves it to the Bin with an Undo toast. Keyboard: ↑/↓ select, Enter previews, F2 renames, Delete removes.

Sharing works like notes: a file inherits its folder unless it has its own setting, and recipients can only preview and download.

Metadata is not stripped. MyNotes does not remove EXIF or embedded metadata (such as GPS location or author) from images or PDFs. Remove it before sharing.
Using MyNotes

Bin

Deleted notes and files stay in your Bin for exactly 30 days. Retention is fixed.

  • Everything is kept: drafts, versions, file bytes, and sharing. Nobody can read a binned item, including MCP clients.
  • Restore returns an item to its original folder, or to Default if that folder is gone; the toast names the folder and any sharing that returns.
  • Blank notes that were never published skip the Bin.
  • Delete forever and Empty Bin remove items permanently. An hourly sweeper, also run at boot, removes expired items.
  • Binned files still count towards the storage quota.
Upgrading from 0.3.0 or earlier: notes deleted before the upgrade (described as permanent at the time) reappear in the Bin for 30 days, then are deleted. Empty the Bin if you do not want to keep them.
Self-hosting

Quick start with Docker

You need Git, Docker Engine, and Docker Compose. Bun stays inside the image.

1

Clone and configure

git clone https://github.com/pankajsoni19/mynotes.git
cd mynotes
cp .env.example .env
mkdir -p /srv/mynotes

Set MYNOTES_DATA_DIR=/srv/mynotes. The directory must be writable by UID 1000.

2

Secure trusted accounts

ALLOWED_EMAILS=you@example.com,partner@example.com
TOTP_POLICY=required
TOTP_ENCRYPTION_KEY=<openssl rand -base64 32>
Keep the encryption key. It is not included in data backups.
3

Build and start

APP_VERSION=0.4.0 GIT_SHA=$(git rev-parse --short HEAD) \
  docker compose up -d --build

Open http://localhost:2026. The first account can be created while the database is empty.

4

Verify

curl http://localhost:2026/api/health
docker compose ps

Access

Accounts and sharing

Adding users

Add trusted addresses to ALLOWED_EMAILS, temporarily set ALLOW_REGISTRATION=true, restart, and let each person register. Disable registration afterward.

Permission precedence

Notes are private by default. Folder access applies to inherited notes, but explicit note access always wins. Nothing becomes public.

Authentication

Two-factor authentication

The grouped setup key is entered once in an authenticator app. Sign-in uses the current six-digit code or one complete recovery code.

Recovery codes are encrypted. Viewing or replacing them requires a password and fresh TOTP code. Each works once.

Administrator reset

docker compose exec app bun server/reset-totp.ts user@example.com

This revokes the user’s sessions and requires fresh enrollment.

Data

Storage and migrations

On-disk layout

/data/
├── mynotes.sqlite
├── notes/<note-id>/
│   ├── current.md
│   ├── draft.md
│   └── versions/000001.md
├── documents/
│   ├── objects/<document-id>
│   └── .staging/<document-id>.part
└── backup/

File names live only in SQLite; bytes are stored under server-generated ids. Uploads stream to .staging on the data volume.

Automatic upgrades

Numbered migrations run transactionally before traffic is accepted and are recorded in schema_migrations.

Released migrations are append-only.

One instance per data directory. Upload slots, locks, and the sweeper live in the process.
Operations

Backup and restore

The backup script briefly stops the app for a consistent snapshot of SQLite, notes, and files, verifies gzip, and keeps five weekly archives.

./scripts/backup.sh
./scripts/backup.sh --force

Restore into an empty directory

mkdir -p /srv/mynotes-restored
tar -xzf /srv/mynotes/backup/mynotes-*.tar.gz -C /srv/mynotes-restored
MYNOTES_DATA_DIR=/srv/mynotes-restored docker compose up -d --build
  • Archives include documents/objects but not documents/.staging.
  • Archive size and the time the app is stopped grow with stored files; gzip gains little on media, and five archives multiply the disk use.
  • Binned items are backed up like live ones. Anything deleted forever can survive in older archives for about five weeks.
  • Start only one MyNotes instance on a restored directory.
Store .env separately. Backups intentionally exclude it and its TOTP key.
Networking

Network and HTTPS

Compose publishes port 2026 for LAN access. Prefer Tailscale Serve or a TLS reverse proxy for HTTPS.

  • Use HTTPS for non-local access.
  • Set APP_ORIGINS to a comma-separated list of exact trusted origins.
  • Keep COOKIE_SECURE=true with HTTPS.
  • Plain HTTP requires COOKIE_SECURE=false and is less safe.
  • Never serve the data directory as static content.
Security

Security model

Application

Argon2id passwords, opaque HttpOnly sessions, SameSite cookies, CSRF tokens, CSP, and authenticated file reads.

Data

AES-256-GCM TOTP data, restrictive permissions, symlink refusal, atomic writes, and mutation locks.

Container

Non-root UID, read-only root, dropped capabilities, no-new-privileges, and a small tmpfs.

Supported shape: a single Docker Compose host using local SQLite/WAL storage. Rate limiting is in memory and does not coordinate across replicas.

Help

Troubleshooting

Container cannot write data

Ensure the host path exists and is writable by UID/GID 1000.

Login fails behind a proxy, Tailscale, or LAN address

Add the exact scheme, host, and port to APP_ORIGINS. Plain HTTP also needs COOKIE_SECURE=false; prefer HTTPS.

TOTP code is rejected

Synchronize phone and server clocks. Codes are one-time; use a fresh code or recovery code.

Inspect service health
docker compose logs --tail=200 app
docker compose ps
curl http://localhost:2026/api/health
